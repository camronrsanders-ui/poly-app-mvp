# Polycircle Screen Map

## Public/Auth
Welcome → Sign Up / Log In
Sign Up → Onboarding
Log In → Onboarding if incomplete, otherwise Discover
Forgot Password → Log In

## Onboarding
1. Welcome
2. Basics: display name, age/date of birth, city/region
3. Identity
4. Pronouns
5. Orientation
6. Relationship Structure
7. Current Relationship Status
8. Intentions (multi-select)
9. Discovery Preferences
10. Profile bio/headline/interests
11. Photos
12. Build Your Circle (relationship cards, skippable)
13. Privacy
14. Finish → Discover

## Main navigation
- Discover
- Connections
- Circle
- Messages
- Profile

## Discover
Discover feed → Full Profile → Like/Connect or Pass
Filters → age, distance, relationship structure, intentions, identity/preferences

## Connections
Connections list → Profile or Conversation

## Circle
Relationship Cards list → Add Card / Edit Card
Future: visual polycule graph

## Messages
Conversation list → Chat → Profile / Block / Report

## Profile
My Profile → Edit Profile
Settings → Privacy / Account / Safety / Log Out

## Safety
Report User
Block User
Community Guidelines

## Core navigation rules
- Unauthenticated users cannot enter authenticated app screens.
- New authenticated users with onboardingComplete=false go to Onboarding.
- Completed users enter Discover.
- Blocked users cannot bypass restrictions through profile or messaging routes.
