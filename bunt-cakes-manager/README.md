# Bunt Cakes Game Day Manager

Mobile-first kickball captain tool.

## Included
- Scorekeeping: Bunt Cakes score, opponent score, balls, fouls, and outs
- Full-position-name field diagram for every inning
- Editable pitcher rotation
- Kicking-order tracker
- Attendance
- Add, remove, or rename players at any time
- Editable pods
- Installable Progressive Web App
- Offline support
- Shareable state links
- JSON backup/import

## Current roster design
The roster is intentionally dynamic. Captains can add missing players later without rebuilding the app.

## Deploy
This is a static site and can be deployed to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or similar.

## Sharing model
A shared link contains a snapshot of the current game state. Edits are not live-synced across phones yet. Real-time captain/team synchronization can be added later with a cloud database.
